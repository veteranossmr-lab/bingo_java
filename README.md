# Bingo Sostenible ♻️🎲

¡Bienvenido! Este es un bingo para jugar con amigos o compañeros, con un toque especial: para cantar **bingo** tendrás que demostrar que sabes de **sostenibilidad**, sobre todo la aplicada al mundo informático.

## ¿Qué necesito para jugar?

- Un ordenador con un programa que pueda ejecutar java  (el nuestro es eclipse)
- De 2 o más jugadores. El juego está pensado para partidas **multijugador**.

## Cómo empezar

1. Abre el programa del bingo.
2. Indica cuántos jugadores van a participar y escribe el nombre de cada uno.
3. Cada jugador recibe automáticamente su cartón. No hay que hacer nada más.

## Cómo se juega

1. **Salen las bolas.** En cada turno el programa saca un número al azar. Nunca se repite ninguno.
2. **Se marca solo.** Si el número está en tu cartón, el programa lo marca por ti. Tampoco tienes que comprobar tú si tienes línea o bingo: el juego lo detecta de forma automática.
3. **Los datos siempre a la vista.** La pantalla muestra con claridad el número que ha salido, los números ya cantados y el estado de cada cartón.
4. **Línea.** El primero que completa una línea del cartón lo anuncia el propio juego.
5. **Bingo.** Gana quien complete todo el cartón.

## La prueba de sostenibilidad 🌱

Antes de dar por bueno un bingo, el juego lanza una **pregunta aleatoria** sobre sostenibilidad. Si respondes bien, el bingo queda validado. Si fallas, la partida sigue.

Las preguntas tratan de cómo cuidar el planeta desde el sector informático: ahorro de energía, reciclaje de equipos, vida útil de los dispositivos, centros de datos responsables, etc.

Algunos ejemplos del tipo de preguntas:

- ¿Qué es mejor para el medio ambiente: alargar la vida de un ordenador o cambiarlo cada año?
- ¿Qué se puede hacer con un equipo electrónico que ya no funciona?
- ¿Qué ajuste de un ordenador ayuda a gastar menos energía?

## Consejos para pasarlo bien

- Jugad atentos a la pantalla: el programa os avisará de todo.
- No pasa nada por fallar una pregunta, ¡es una forma divertida de aprender!
- Si hay dudas, repasad las respuestas al final de la partida.
